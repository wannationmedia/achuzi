# Lean setup — cut token burn without losing capability

**Why tokens vanish:** every message re-sends the whole chat AND the descriptions of every
enabled plugin/skill/connector. ACHUZI needs about 6 of the hundreds loaded.

## Keep ON (ACHUZI work)
- GitHub / repo access (claude-code-remote)
- Memory (so new chats know you)
- Figma or Canva (only when designing assets)
- Gmail + Google Calendar (COO/PA duties, on demand)
- Notion or Google Drive (only if you store docs there)

## Switch OFF (click-by-click, claude.ai in a browser)
1. Open **claude.ai** → click your name (bottom-left) → **Settings**.
2. Open **Connectors**. Click each one you don't use this week → **Disconnect** or toggle off.
   Typical removals: Wix, Webflow, Lovable, Make, Slack, Stewdio, Picsart, HeyGen, Fiverr,
   Product Hunt, Twilio, Cloudflare, AgentMail, Firecrawl (re-enable when needed).
3. Open **Capabilities → Plugins/Skills**. Disable bundles unrelated to building the app
   (e.g. finance/legal/HR/sales/clinic/film packs).
4. In the Claude desktop app: **Settings → Plugins** — same idea.
Re-enable any of them in 10 seconds when a task needs it. Switching off is not deleting.

## Session rhythm (the real saver)
- One task = one chat. Finish -> `HANDOFF.md` updated -> commit/push -> `/clear`.
- Start each new chat with: "Read HANDOFF.md and continue with Next Step 1."
- Long chats get expensive per message; a fresh chat with HANDOFF.md costs ~1-2k tokens.
- Ask for results, not narration: "Do it, then give me a 5-line summary."
